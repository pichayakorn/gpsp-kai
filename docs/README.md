# Documentation

Building, installing and the changes made in this repository are described in
the [main README](../README.md). The files here are the original
documentation. Most are takka's Japanese notes, kept for reference; some
details describe older versions.

| File | Language | Content |
|---|---|---|
| `changelog_jp.html` | Japanese | Release log of gpSP kai, from the first kai builds to 3.4 test 4 |
| `changes_3.0_to_3.1_jp.txt` | Japanese | Changes from 3.0 to 3.1: CPU fixes for specific games, BIOS calls, video and sound |
| `readme_original.txt` | English | Exophase's original gpSP readme and release log (up to v0.9), with the credits |
| `readme_jp.txt` | Japanese | Short readme: kai is based on Exophase's gpSP; see `readme_original.txt` |
| `manual_jp.txt` | Japanese | Outline of a planned manual; also lists the savestate format versions and their file sizes |
| `install_jp.txt` | Japanese | Installation for CFW 5.00 M33-era firmware, including the discontinued XMB update feed |
| `config_file.txt` | Japanese | Format of the config files as of 3.2 test 06: `dir.cfg`, `*.fnt`, `*.msg` and the binary `gpsp.cfg` (partly outdated) |
| `cheat_jp.txt` | Japanese | Cheat file format: `[ROM name].cht` in the cheat folder from `dir.cfg`, UTF-8, up to 30 codes; supported formats (GameShark v1-v3, Pro Action Replay v1-v3, direct v1-v3) |
| `frame_skip.txt` | Japanese | Design notes on auto frameskip and fast-forward, with the timing of one emulated frame |
| `tv_out_jp.txt` | Japanese | Technical notes on PSP-2000 TV output through Dark_Alex's `dvemgr.prx` |
| `licenses/` | English, Korean, Japanese | License notices of the bundled fonts (`knj10`, `batang`) and the FBM print library |
